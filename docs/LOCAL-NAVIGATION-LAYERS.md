# 分层局部地图与短段路线

181在原有圆盘覆盖诊断之外，增加了独立的局部地图、矩形扫掠检查和可点选目标的路线预览。此页和回放不会发出电机指令；原有教路线控制仍走原来的控制入口。不能把路线预览写成已经完成实车自主绕障。

## 地图怎样保存证据

地图在当前有效定位会话内保留半径1.5米的局部窗口。5厘米逻辑网格分为四个2.5厘米支持小格；每个小格至少有两个不同Raw时间戳的贴地观测，才建立地面支持。重复或重投影Raw不增加票数。不跨空洞填图，不把初始车身或近处盲区自动涂成空地。

- **静态地面支持**：停顿不会随旧诊断的3秒计时一起消失。累计平面变化超过2厘米或约2度、定位中断、短时位置跳变、重选地面或暂停扫描会清除当前证据；滚出窗口后重新进入也须重新观测。
- **近期空地**：有地面支持且最近2秒内有该小格的贴地Raw观测。旧支持转成蓝色，仍保留地面记录，但不能直接作为当前动作的空地证据。短段检查另要求全局最近Raw年龄不超过250毫秒。
- **障碍与落差**：一个有效Raw点立即阻挡，单帧告警和多帧障碍分开显示；不会因为过了几秒就变空地。消除低障碍须有三个较新的独立Raw观测，其射线真正穿过记录的障碍位置和高度，并终止于其后方。高处射线、同格地面点或超时都不能代替。落差须有三个后续贴地观测。
- **未知**：无测量、观测不足和遮挡仍为未知；不会用平面拟合外推整个地面。

当前分层地图只接入经过置信度过滤的Raw。已验证完整深度继续参与旧地面诊断和叠加，但没有被当成独立Raw观测投票或清障。所有“空地”仍是有限分辨率下的观测分类，并非接触传感器或独立精度验收的替代品。

## 下一段怎样检查

`LocalTrajectory`使用真实宽15厘米、长10厘米的带朝向矩形，保留默认5厘米余量，另加假设1厘米定位/安装误差。对整段平移与旋转作连续覆盖检查：相邻姿态任意角点运动不超过5毫米，并把半个采样间隔的解析误差再扩入矩形。检查所有相交小格，包含起步位置、车尾、转弯中途和停止延伸。

界面展示假设直行2厘米及左右各10度。直行额外检查1厘米停止距离，转向额外检查约2.9度停止角。这些是**诊断参数，尚未由LOOI实测标定**，不能把100毫秒写成2厘米。报告中持续标记安装未标定、没有种入初始足迹、`motionAuthorized=false`。

旧的10厘米圆盘覆盖诊断不参与新路线许可。单元场景验证了：同样5厘米余量下，30厘米已观测走廊的旧覆盖中心为0，矩形短直行可通过，但原地转身仍会被阻止。

## 怎样分步规划

在“局部分层地图”点选目标。A*在带朝向的状态中使用5厘米格的前进和45度转向，每条边都调用同一个扫掠检查，包括停止延伸。目标未全部可见时，可返回朝目标推进、邻接未知的**已知空地边界**；到边界后必须重新观察和规划，不跨未知区域。计算窗口约2米、最多400个展开状态，超出预算或无可达边界有明确等待原因。

规划在独立工作线程进行；地面基准、目标、位置、朝向或观测时效变化后，丢弃过时结果。黄色路线只是预览，不调用BLE；语义识别“罐子后面”和逐段执行后的无进展检测/实车闭环还未接入。

## 已保存数据的实际结果

同74份已保存双深度记录，通过实际编译的生产Kotlin类重放：局部分层保留地面峰值485小格、近期空地峰值333、单帧告警峰值129、多帧障碍峰值356、落差峰值51。这里是2.5厘米小格，不能与旧10厘米诊断的10格直接比较。

当前车位的假设2厘米直行：36份因未观察范围被阻止、1份有障碍、37份缺新鲜Raw，没有输出可行驶结论。36份缺观测都包含起步足迹缺口（116～121小格）；说明新的直接阻点包含**镜头附近的起步盲区和未标定安装位置**，不是一句“圆盘候选0”或整屋地图不全。也不能由此推断车旁实际没有空间。

下一项实物工作是固定最低头部、标定镜头到底座中心的水平偏移、脉冲位移/转角和停车延伸，并在明确人工确认的起步区域核对近处盲区；不会默默把盲区标成传感器测得空地。用户手动连接底座后再安排短动作，无须重复之前的盲扫。

验证包含：静态支持保留/近期观测失效、重复Raw、遮挡空洞、单点阻挡、占据不随超时消失、实际高度射线清障、高射线不清低障碍、基准切换、矩形和转弯、停止范围、已知障碍绕行、未知目标的可达边界，以及补图后继续到达目标。模拟验证不替代真实地面验收。
