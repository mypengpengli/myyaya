## 明确后续阶段

- Azure / 音色切换：当前完全不用，沿用已接受的中文声音。
- 认人 / 身形身份：暂缓，任何人均可唤醒对话。
- 声源定位、跟随、靠近和房间导航：需要感知、距离、定位与运动闭环的真实方案；不是等硬件到货后已有功能自然出现。
- 指定微信 / 邮箱自动发送：需要真实发送通道、账户与收件人处理，尚未实现。
- Hermes 浏览器真实画面：须接实际截图接口；当前仅真实文字进度。

实现入口：手机 `src/agent`、`src/artifacts`、`src/hermes`、`src/search`、`src/device-tools`，原生文件/相机/语音模块和 `server/file_bridge.py`。核心仍采用现有 TypeScript / Kotlin，不另建一套架构。
