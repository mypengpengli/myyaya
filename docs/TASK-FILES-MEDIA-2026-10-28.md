# 2.1.157–159：媒体播放、文档与 Hermes 交付

本轮开发范围为媒体语音控制、文件预览、Hermes 文件回传与完成汇报。认人、跟随、声源定位、房间导航和微信/邮件发送继续按原清单留到后续阶段。未新增文字对话入口。

## 媒体播放

`viewer_control` 新增 `play`、`pause`、`replay`、`seek(seconds)`，`status` 返回当前视频真实时间、时长和播放状态。工具绑定到当前挂载的原生播放器，关闭后释放绑定；旧页面的清理不能取消新播放器。跳转限制在实际时长内，加载失败时不谎称播放成功。重播和跳转同步清除旧的结束倒计时；视频仍需实际播放结束才开始 10 秒关闭计时。

## 文件保存与预览

作品页可以通过 Android 系统文件选择器导入文件，单文件上限 25 MiB，复制进应用私有作品目录。只读取用户选中的文件，不申请整盘读取权限。图片与 MP4 继续使用原 Viewer。

- PDF：Android `PdfRenderer` 实际逐页渲染，支持上一页/下一页，位图尺寸和缓存数量受限。
- DOCX：离线读取正文、段落和表格文字。
- PPTX：按幻灯片顺序显示逐页文字。
- TXT/Markdown/JSON：本地文本预览，不执行 HTML、脚本或文档宏。
- 原 DOC/PPT 以及不适合简化预览的文件：通过只读 FileProvider 交给手机已有应用打开。

**Word/PPT 直接交付可编辑的 DOCX/PPTX 原文件**。APK 内提供内容预览，图片、动画、字体与完整布局通过“打开原文件”交给 WPS 等手机已有应用显示。用户也可“保存原文件”到所选位置，拿到独立的文件本体。没有强制依赖 WPS，系统会选择支持该格式的应用。

根据用户 2026-10-28 补充，不自动在服务器转 PDF，只有用户明确要求 PDF 时生成 PDF；原格式始终保留。刚加入的自动转换实验已撤回，从未部署到服务器或装入 158 APK。服务器无需安装 LibreOffice。

157 实机发现系统文件选择器会被既有 5 秒后台退出机制打断；158 的导入流程复用已有 `withExternalActivityLease`，等待选择和登记结束才释放。麦克风/BLE 仍按后台策略暂停，不删除正常后台退出机制。PDF 同时增加 1–4 倍缩放和滚动。

## Hermes 文件桥

实测 `/v1/capabilities` 可用，但当前旧浏览器控制能力 `enabled=false`；该版本的原附件下载被同一开关限制，不能当作通用产物传输。源代码参考 [当前服务器版本 API Server](https://github.com/NousResearch/hermes-agent/blob/1744a19/gateway/platforms/api_server.py)。新版上游还存在协议移除变化，因此本轮使用独立、版本化的窄接口，不改 Hermes 主流程。

服务代码与部署说明见 [server/README.md](../server/README.md)。仅新增同源 `/myyaya/v1/*`，监听本机 8651，复用服务器环境中的 Bearer 鉴权。APK 只请求固定清单/下载路径，不接受模型自由提供的下载 URL，也不向其他主机转发 Token。

已按用户此前授权通过服务器 Hermes 完成部署，部署 Run 为 `run_e5d229b84b8d4bf1a2993d2c9a24c3fd`。服务器核对三份源文件 SHA256、通过两项测试、启用用户级服务；备份域名配置后新增 OpenResty 精确路径反代，`nginx -t` 通过才 reload，没有重启 Hermes。本机独立请求 `/myyaya/v1/capabilities` 返回 200 与 `myyaya-files-v1`，`/health` 也返回 200。服务器报告无 Token 的新接口为 401，原 `/v1/capabilities` 仍为 200。

生成文件的任务在持久化时附带唯一手机任务编号。Hermes 将产物写到 `~/myyaya-output/<task_id>/`，通过 `file_bridge.py publish` 发布私有快照。桥拒绝其他任务目录、目录穿越、超限文件和未知格式；清单含稳定编号、字节数和 SHA256。手机在下载完成并核对大小、SHA256 后登记作品，重复取回沿用稳定编号，不重复派发原任务。

文件下载失败与服务器任务失败分开记录。任务已经完成但文件未取回时，明确显示该事实；任务页可以“重试取回文件”，不会再次让 Hermes 制作同一文件。

## 过程与完成汇报

手机 Agent 提交任务并收到 run_id 后自动打开该任务的过程页，显示真实 SSE 活动；期间仍可对话。服务器任务继续独立执行。

任务终态与文件接收状态持久化。完成、失败、取消和中断会显示通知；汇报在中文语音空闲、没有拍照确认或录像占用时播出，保留停止监听。没有启用语音时保留可见通知。播报后开 15 秒追问窗口。用户打断已开始的播报后，不反复重播同一通知。

结果资料排入当前手机 Agent 的后续上下文，含真实状态与已接收作品编号，用户可以继续要求打开或处理文件。后台结果不作为新的用户命令执行。切换 Hermes 地址或 Token 后，不查询、下载或汇报其他绑定的任务。
