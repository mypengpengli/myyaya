# 表情首页、首次授权与设备连接

2026-10-27 用户反馈：日常页面应以表情、声音和简短标签为主；启动先完成授权和连接，菜单由右向左滑动打开。目标设备是 Android ARM64 手机，包括小米 12 Pro、红米 K50，不固定某个机型。

当前 **2.1.159 联调 APK 已生成并安装到手机**，尚未公开发布；下载页仍为 2.1.152。新增媒体控制、文档预览、文件回传和完成汇报；服务器生成三种文档到手机打开、DOCX/PPTX 原样保存的闭环已通过。Word/PPT 可用 WPS 等应用打开原件，不自动转 PDF，详见 [媒体与文件交付](TASK-FILES-MEDIA-2026-10-28.md)。相机和语音专项等用户方便说话时再测，不新增文字入口。最新证据与限制见 [手机验收](PHONE-CHECK-2026-10-28.md)。下文包含 153 起的交互设计。

## 交互规则

1. 新安装及从旧首页升级后，首次进入“权限授权 → 搜索并连接 LOOI → 验证中转站与对话模型 → 表情首页”。迁移标记独立保存，不清除原有设置、服务 Token 或任务数据。
2. 授权页请求附近设备、麦克风和相机。拒绝后提供重试、系统设置和稍后处理；设备连接默认立即搜索，也允许明确选择稍后连接。
3. 首页保留全屏表情；底部靠左以 10sp、低对比度的一行小字显示公开执行进度，例如“正在听”“正在拍照”“正在整理结果”。不展示模型内部推理，不显示本地模式、手动底座操作、任务入口和语音测试按钮。
4. 左滑打开菜单，右滑或关闭返回表情。菜单提供连接、语音与声音、设置和任务记录；原有 legacy 照片选择入口移动到菜单。
5. 完成引导且麦克风已授权后，中文唤醒默认启用。菜单、设置和任务页属于同一个前台 App，不因这些视图切换而重新申请麦克风权限或关闭语音。
6. 真正切到 Android 后台或休眠时关闭采音；前台恢复、手动唤醒后自动恢复。用户可以在语音设置中关闭自动唤醒，诊断按钮只在该设置页展开显示。

## Android 授权与蓝牙

| 系统 | 连接所需权限 |
| --- | --- |
| Android 12 / API 31 及以上 | `BLUETOOTH_SCAN` + `BLUETOOTH_CONNECT`；扫描声明 `neverForLocation`，不把精确位置授权作为连接前置条件 |
| Android 7–11 / API 24–30 | 前台位置权限，扫描时还需系统定位开启 |
| 支持的 Android 版本 | 语音需要麦克风；本地人脸注视需要相机；拒绝某项不伪造可用状态 |

相机、麦克风、蓝牙与位置采用系统实际可提供的授权选项，不能由 App 自行授予“始终允许”。日历修改与跨 App 悬浮窗当前未实现，因此本次不加空授权入口。[Android 蓝牙权限](https://developer.android.com/develop/connectivity/bluetooth/bt-permissions)

扫描按两路名字 `name / localName` 和 LOOI 服务识别，兼容空的缓存名字及短 UUID；允许重复广播，以便取得后续扫描响应中的名字。结果即时显示，离开引导会取消扫描；选择设备后等待扫描释放再建立 GATT。蓝牙关闭、无权限和扫描为空分别提示，保留手动重试与断线重连。

这些是软件问题的修正，不代表已确认用户底座的实际失败原因。底座是否进入广播状态、官方 App 是否占用连接、固件/硬件兼容性仍需实测。引导中的通电和长按提示依据 [LOOI 官方配对说明](https://looirobot.zendesk.com/hc/en-us/articles/52405108577561-How-to-Sync-Phone-with-LOOI)；不会自动重置或删除官方 App 的配对。

## 当前唤醒方法

复用 APK 内置的 **Vosk 中文本地识别**。识别文本通过“小丫小丫”的唤醒门控与严格口令解析器，15 秒内可连续说受支持动作，“停止”无需唤醒。无需联网或模型 Key；不是厂商官方 App 的专有唤醒实现。

开发代码已接入 Pi 1.4.0 工具循环、NewAPI 流式对话和系统中文 TTS：唤醒后提交完整句子，回复结束后保留 15 秒追问窗口；停止、触摸打断与后台状态会使迟到回复失效。协议与语音行为测试通过，原生 APK/真实声学效果仍在验证。试听放在语音设置。本地注视不等于人物身份识别或自主跟随。

2026-10-27 用户允许首版手动停止录像。录制时画面保留“停止录像”按钮，暂停中文识别以释放麦克风，保存后恢复；不宣称录制过程中还在监听停止口令。照片、录像保留稳定编号，可在“作品与录像”重新打开；图片加载完成后、视频真正播放结束后才开始 10 秒收起计时，固定的作品保持显示，后续结果排队。

## 验收清单

- 全新安装和旧版升级都先出现新引导；完成后重开不重复。
- Android 11 与 12+ 选择正确权限；拒绝和永久拒绝能恢复，不自动越权。
- 蓝牙关闭时提示打开；扫描结果逐步出现；退出后无迟到结果；选择设备等待扫描停止后连接。
- 首页无调试按钮，横向左滑打开菜单，纵向动作不误触；点击表情交互与触摸停止保留。
- 授权后自动监听，普通菜单切换不打断；后台/休眠停止，返回后恢复；迟到的权限查询不重启旧会话。
- 对小米 12 Pro、红米 K50 分别记录 Android API、ARM64 ABI、系统中文 TTS、BLE 和唤醒效果，不硬编码机型判断。
- 新版用原永久签名覆盖升级并保留数据；当前没有完成 APK 构建和这项真机验收。

本轮源码验证：TypeScript、前台语音生命周期、权限选择、生成 manifest、增量扫描与取消、首页交互，以及现有运动与 BLE 检查。完整 Linux 检查由 GitHub Actions 运行；验证记录见 [STATUS](STATUS.md)。
