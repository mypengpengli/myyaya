# 地面、障碍与候选通行区域

实现版本：2.1.175。手机本地几何计算，不依赖 Gemini Live、Robotics ER 或其他云模型。此阶段显示观测结果，不包含路径规划或自动行驶。

## 操作

1. 左滑菜单 → 房间地图 → 打开房间地图。新建地图，或打开能够恢复定位的旧地图，开始扫描。
2. 后摄看向实际地面，缓慢移动让 ARCore 检测平面和原始深度。新地图没有参照图也可以在本次会话中测试；重新进入后若不能恢复定位，需新建地图或使用固定参照图。
3. 点“底座尺寸”，填写整车最大宽度、前后长度、装好手机后的最高高度及余量。设置保存在当前手机，APK 不预置用户的尺寸。余量默认5厘米，可调整。
4. 点“点选平面”，再点击左侧后摄画面中的实际地面。只接受已跟踪、命中多边形内部的向上水平面，再选择“实际地面”。**水平桌面也可能被 ARCore 识别成平面**，不能按最低或最大平面自动认定为地板。
5. 确认后缓慢扫描地面与障碍。右侧上方新增局部判断图，原表面地图在下方，右侧可滚动。图上方表示后摄方向；按当前安装方向对应底座倒车观察方向，未完成外参标定。

没有实际地面视野时，不要用桌面代替地面做整车通行验收。透明或反光瓶、细线、低矮物体可能没有有效深度，不能因为未出现红点而认为没有障碍。

USB不便移到地板时，可以在确认框选择“台面试验”。这会明确显示“台面试验（非地板）”，只验证相对该平面的高度分类和几何包络；诊断 `surfaceRole=bench-test`、`groundSelected=false`、`candidateCenterCells=0`，试验中的绿色数量单列为 `benchCandidateCenterCells`。台面试验不能记为真实地板验收。

## 颜色与数据

| 颜色 | 含义 |
| --- | --- |
| 灰色 / 空白 | 未知、观测不足或不能确定；没有通行授权 |
| 青色 | 最近被重复观测的地面单元 |
| 红色 | 高出已选地面、落在整车高度范围内的障碍观测 |
| 橙色 | 低于已选地面的落差或异常深度观测 |
| 绿色 | 整车包络覆盖的全部单元均满足近期地面证据的候选中心，不是已验证路线 |
| 白圈 | 以相机投影为中心的整车包络与余量；相机尚未标定到底座中心 |

- 使用 Raw Depth 与置信度153/255，不使用平滑深度插值填空。深度是相机Z距离，投影复用表面建图的纹理内参和原始采样步长。
- 输入相机Z距离0.2～4m，水平分析半径3m，10cm网格，最多4000个单元。仅接受本次会话定位有效、非未来、距相机帧不超过250ms的新深度时间戳。
- 地面距离容差为±2.5cm；高出3cm至整车高度加5cm的观测标为障碍，低于地面4cm标为落差；边界、过高表面及粗糙区域保留不确定。这里的阈值尚未通过真实地面精度标定。
- 一个地面单元至少需要3个独立深度帧，且10cm单元内至少3个四分区有观测。帧和四分区的证据各自最多保留3秒，重复/重投影深度不刷新证据。
- 相机相对所选平面高度暂限3cm～2.5m；下限允许低位安装的手机，不是已完成的安装高度标定。
- 包络半径为 `sqrt(宽² + 长²) / 2 + 余量`，覆盖整车矩形转向时的对角线范围。只有与该圆相交的所有网格均为近期地面且无障碍、落差或未知，才显示绿色候选中心；不将整个AR平面多边形或黄色行驶轨迹填成空闲。
- 尺寸缺失时仍显示地面和障碍，但不计算绿色候选。观测过期、定位中断、平面丢失、暂停、重开、切换地图时清除判断。平面高度或朝向显著改变也清空旧证据。

## 当前边界

这是短期局部表面证据，不是已证明无碰撞的三维自由空间；不包含透明障碍补偿、3cm以下物体可靠识别、坡面/台阶通过性、悬空空间完整检查、轮履打滑、停止距离或电机控制。没有相机到底座的平移/旋转外参，不能把相机投影直接当成真实底座中心。因此所有诊断均明确 `motionAuthorized=false`、`motorControl=false`。

地面选择与判断不写入 `.yayamap`，避免下次打开把历史绿色区域当作当前证据；既有地图格式保持兼容。底座尺寸单独保存在当前手机。原始诊断在 `roomMap.terrain` 中，包括地面/障碍/落差/候选数量、相机离地高度、尺寸和时效。

原生测试覆盖新鲜度、重复深度、空间覆盖、未知空洞、窄通道、障碍和落差优先、完整包络、证据过期、平面变化、会话重置与非法输入。实机是否真正识别地面、瓶子及候选区域，应分别记入[手机记录](PHONE-CHECK-2026-10-30.md)，测试通过不等于这些实物项目通过。
