# 视觉记路与多个地点

这版在已有地图、ARCore 和 OpenCV 上增加相机视觉地标，用于恢复保存地图的坐标。地点继续使用独立 UUID，视觉地标、家庭路线和任务都跟随所属地图。

## 使用流程

1. 在导航页面新建地图并开始扫描，让后摄观察门框、柜边等固定、有细节的场景。定位有效时自动采集地标，页面显示已保存视角数。
2. 缓慢改变视角或位置，记录多个方向。每张地图保留最多12个视角，每个视角最多400个地标，同时保存灰度建图照片和相机内参。
3. 保存地图，结束相机后重新打开同一地图，开始扫描并观察之前记录过的场景。识别通过后显示“视觉地标对齐”，位置接回现有地图。
4. 如果识别到了另一张地图，点击“识别当前地点 / 切换地图”确认使用该地点，再开始扫描恢复位置。
5. 搬家或到全新地点，点击“搬家 / 新地点”。也可在普通对话中说“小丫小丫，我们搬家了，这里叫新家”，由 create_home_location 工具建立独立地图。在导航相机页，同一句命令由本地语音解析处理。

## 实现

- 学习时读取CPU相机灰度图、对应内参、ARCore点云与地图变换。SIFT图像特征与投影误差不超过3像素的点云关联，至少24个三维地标才保存一个视角。
- 点云关联不足时，再用同一有效地图内的多个相机视角三角化。最近保留最多8帧，时间差不超过15秒、基线5厘米至1米，检查正深度、双向重投影误差和至少1.5度视差。地图坐标恢复前的图像不参与学习。诊断状态分别返回点云、图像特征、直接关联和三角化数量。
- 恢复时用FLANN、欧氏距离和比率筛选匹配，PnP RANSAC估算位置与朝向。至少12个内点、55%内点比例、画面多个区域和平均重投影误差不超过2像素。
- 检查点位于镜头前方、重力方向一致、多地图匹配有足够分差。连续三次地图到当前会话的变换一致，并具备多个保存视角的支持或相机位置/方向变化，才接受结果。
- 通过识别得到的变换创建当前 ARCore 会话锚点，再交给 RoomMapper 和已有家庭导航。相机暂停、会话改变、锚点停止跟踪后需重新恢复。
- 视觉文件使用 AtomicFile，保存在 room-maps/visual-landmarks。旧地图数据格式保持兼容。旧地图需先在有效定位时采到地标，才能通过这种方式恢复。
- 本轮早期试验的ORB地标格式为版本1，SIFT地标格式为版本2。版本1地图本体继续使用，视觉视角需要重新采集。
- 后台单工作线程处理特征与文件，每400毫秒最多采样一次，任务繁忙时跳过采样。ARCore对象在相机线程读取，OpenCV对象在工作线程释放。录制回放模式跳过视觉写入。
- 保存视角的最小间隔改为6厘米或约7度，适应8厘米镜头高度。诊断同时报告原始点云数量、年龄和筛选后的数量。已有点云在两秒窗口内与当前图像关联，恢复位置仍需经过几何校验。
- 自动识别当前搜索最近保存的 8 张地图及当前地图。更早地点可手动打开后识别。

## 验证范围

2026-11-23追加记录：原始点云时间戳实测比相机帧快约32毫秒，已允许100毫秒的前向容差并增加回归测试。发现360手机助手的USB安装请求反复使App进入后台，早期录像实际只有25.3秒。手动录制改为最多5分钟，切回同一会话时分段接续并保留同批片段；同一会话恢复时保留锚点并复用已有配置。

持续日志保存在navigation-probe/visual-evidence，记录每个已处理画面的时间、相机位姿、特征数量和阶段。地标副本含灰度JPEG与内参。实拍约55秒的视频已用于离线重建，得到3个视角，6组跨视角几何核对通过。视频时间对齐采用日志估计，误差比较基准为同一录像的ARCore位姿。真实地面距离和整条导航路线的定位精度仍待验证。

新建且尚未记名、带领或执行任务的地图，可使用当前会话的VIO坐标积累初始化地标。几何定位通过后再连接导航坐标。录制回放在独立缓存与visual-replay-evidence目录验证采集，回放的地标不会成为实车地图的定位候选。scripts/evaluate-visual-landmarks.py可在电脑读取版本2地标文件，分别输出自身照片核对和跨视角核对结果。

手机回放采集也得到3个视角，生成的地标文件通过电脑6组跨视角核对。回放方式可选择“建图采集”或“使用已保存地标检查定位”，同一录像使用固定的测试地图编号。回放表面地图同样写入独立缓存，和真实房间地图分开。

2026-11-20真机记录：独立地点创建和新入口已通过。早期ORB版本在点云不足时通过多视角三角化保存2个视角，但重开后的描述子匹配不足，恢复位置未通过。后续改为SIFT，并保存原始分辨率的灰度JPEG与内参以便回放。SIFT识别精度仍需真机验收。

新增坐标约定转换、连续识别一致性、跨地图与跨会话失效、保存地图重新对齐的原生回归测试，以及搬家语音解析回归。编译和回归结果见本次开发交付。

这版尚需实测不同房间、相似家具、新家及旧家的匹配准确率。已有 ARCore 录像未包含这版地标文件，需要隔离的回放建库和识别验收流程，才能用旧录像测端到端成功率。真实地标识别率、耗时和走回原路线的精度均待验证。

全屋未知区域自动探索、自动划分房间边界和可旋转的完整 3D 模型另需对应实现。
