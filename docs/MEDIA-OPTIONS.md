# 媒体比例与模型设置

从 2.1.166 起，模型连接设置分别提供对话、图片（生图 / 改图）、视频模型 ID。旧配置缺少图片 ID 时自动使用 `agnes-image-2.5-flash`，无需重填 Key。设置保存时验证对话连接，不额外生成图片或视频；媒体模型在实际生成时验证可用性。

可说“生成一张九比十六的竖版图片”“把这张图改成横版十六比九”“让这张图动起来，做成正方形视频”。AI 将比例传入 `create_media.aspectRatio`，由任务记录持久化，再分别映射到图片 `ratio` 或视频 `aspect_ratio`。

| 类型 | 支持比例 | 未指定比例 |
| --- | --- | --- |
| 生图 / 改图 | 1:1、3:4、4:3、16:9、9:16、2:3、3:2、21:9 | 生图维持原默认；改图使用参考图尺寸比例 |
| 文生 / 图生视频 | 21:9、16:9、4:3、1:1、3:4、9:16 | 16:9 |

从 2.1.168 起，可说“用 2K 生成一张九比十六的图片”“把这张图提高到 2K，内容别变”“用 4K 改图”。图片 / 改图支持 `resolution=1K/2K/3K/4K`，实际传为 `size`，不会仅写进提示词；未指定维持默认 1K。明确比例时搭配 `ratio`；只指定改图分辨率时从源图像素识别最接近的受支持比例，避免变成正方形，兼容官方输出的像素取整。非标准原图会使用最接近的受支持比例，不能保证任意裁幅原样输出。既不指定比例也不指定分辨率的改图保留此前已验证的具体尺寸请求。

“提高分辨率”未指定档位时，AI 查原任务并升一档，未知时用 2K；已是 4K 时应说明上限，不重复生成。对已有图提高分辨率是新建改图版本，原图保留，不是简单放大显示。2K 是官方档位，不保证每种比例长边都是 2048，例如官方 9:16 的 2K 为 1472×2624，成品以实际文件为准。

视频保持 `size=720P`、默认 5 秒，比例独立传入；不支持图片的分辨率档位。不支持的比例或分辨率在新建任务前拒绝，AI 应说明并询问，不能擅自换值。

生图与改图均请求 `extra_body.response_format=url`，先持久化小回执，再下载成品；下载重试不重复生成。本轮首个旧 Base64 生图响应在十分钟内只接收 52498 字节，结果保留 unknown，未自动重提；该实测促使生图也采用改图已经验证的地址模式。

模型 ID、比例和指定的分辨率在提交任务时保存，重开后提供给 AI 恢复上下文。更改设置后，新任务使用新 ID；旧任务查询使用保存的 ID。旧任务缺失新字段时兼容原默认值。未知结果不会因为改模型、重开 App 或查询失败而自动重提。

协议依据：[Agnes Image 2.5 Flash](https://wiki.agnes-ai.com/en/docs/agnes-image-25-flash) 与 [Agnes Video 2.5 Flash](https://wiki.agnes-ai.com/en/docs/agnes-video-25-flash)，2026-10-29 核对。只支持现有系列的接口格式，不自动探测其他供应商协议。实际成品分辨率以生成文件为准。

自动化验证覆盖旧配置迁移、模型 ID 保存读取、四种生成路径的真实请求体、输入图保留、显式比例覆盖、未指定比例的改图、非法比例提交前拒绝，以及重启后任务模型与比例保留。手机验证结果另见[续测记录](PHONE-CHECK-2026-10-29.md)。
