# 语音控制作品展示：2.1.156

用户暂时不方便说话，相机语音测试保留待测，不添加文字对话入口。先补原需求中的固定与关闭展示。

模型工具 `viewer_control` 支持查询状态、固定、取消固定和关闭。与屏幕按钮操作同一个 `ResultPresentation` 实例，没有第二套展示状态。

- 固定为明确的 `pin(true)`，重复执行不变成取消固定；取消固定同理，重复执行也不延长已有倒计时。
- 图片需加载完成后才计时；视频需真实播放结束后才计时。取消固定仍遵循这些条件，不会给未播完的视频启动关闭倒计时。
- 提供作品编号时，只有当前展示的编号相符才操作；没有作品时如实返回没有展示，不声称成功固定。
- 显式关闭（语音或 X）恢复表情，保留作品和待展示队列；自动倒计时结束仍按原逻辑展示队列中的下一个结果。
- 只控制作品 Viewer，不处理拍照确认框或正在进行的录像。进入后台或调用被取消时不执行。

状态机与工具检查覆盖重复固定、重复取消固定、过期作品编号、后台/取消、带队列关闭、空展示和重新打开；TypeScript 与 Windows 默认 54 项检查通过。语音真机验收待用户方便时进行，不能把自动检查当作实际说话验收。
