# 地板光流与短动作标定

2.1.187 增加地板光流诊断，用来对照 ARCore 平移结果。它还没有参与自主导航、自由空间判断或标定通过判定。

## 为什么增加一条视觉测量

186 在真实木地板上执行一次 200 毫秒后退。头部保持最低，姿态锁和地面参考有效；ARCore 报位移约 2.57 厘米，其中沿后摄方向约 1.48 厘米，方向比例约 0.575，低于现有 0.7 校验门槛，因此拒绝标定。用户没有注意到这次短动作，确认脖子未变，要求下一次动作更明显并提前提示。

录像中地面纹理有位移。用固定 10 厘米镜头高度、相机内参和 ARCore 旋转投影地板特征，离线估计主要沿视线移动约 3.3～3.5 厘米。另一段没有发电机指令的录像，光流结果接近静止，而 ARCore 地图坐标仍有厘米级漂移。这支持继续排查平移估计，不能据此断言实际距离已校准。

原始深度近处仍不足，曾出现中位深度约 20.9 米；增加光流不会自动补齐近处障碍、落差或整车足迹覆盖。

## 手机实现

- OpenCV 4.13.0 随 APK 本地打包；后台单线程跟踪灰度图，立即关闭 ARCore CPU 图像，不在工作线程持有 Frame。
- 使用图像下方限定区域作为人工地板假设，角点与双向光流筛选对应点；按实测固定高度和相机旋转投影到水平面。
- 相似变换 RANSAC 检查内点数、比例、尺度和旋转。特征不足、帧间隔过大、过期或加载失败均单独报告。
- 报告包含参考/样本时间、位移、内点比例、残差和固定高度；每条结果均标明 `autonomousMotionAuthorized=false`。
- 这不是自动地板分割。下方区域被物品遮挡、地毯起伏、头部高度变化或整机被拿起时，固定高度假设可能不成立；拟合残差不是实测距离精度。
- 标定记录同时保存动作前后光流报告。比较位移时必须检查参考时间相同、数据新鲜且拟合有效；重新选取参考之后不能直接相减。

## 更明显的一次人工动作

后退标定可选 200 或 450 毫秒，开始前有三秒可取消倒计时和三声媒体提示音。倒计时结束后重新检查定位、实际地面、固定头部、连接、障碍和控制通道。450 毫秒只用于明确确认的一次人工后退标定；普通导航脉冲上限仍为 250 毫秒，转向未扩大。

失败不自动重试，不放宽原方向判据。先对照录像、光流和 ARCore，再决定是否引入地面约束里程计。低头速度诊断已在 186 获用户确认到达水平最低，但日常 `head_down` 和导航“降到最低”仍是原单字节角度模式；此次导航采用“保持当前位置”。

## 可复核的离线工具

开发机安装 `opencv-python-headless` 和 `numpy` 后运行：

```text
python mobile/scripts/navigation/floor_flow_audit.py recording.mp4 --pose-log probe.ndjson --height 0.10 --output-dir audit --start 2 --end 20
```

要求录制对应的原生位姿日志，包含图像内参、旋转、帧时间和数据集文件名。工具输出 CSV/JSON。它独立于手机实现，当前离线验证环境为 OpenCV 5.0.0，手机使用 4.13.0；两者结果仍需对照，不能假定完全等价。私人录像和日志不入库。

后续还需完成真实动作对照、地板区域可靠性检查，以及如何在低质量 ARCore 平移时约束导航定位。自主导航尚未完成。
