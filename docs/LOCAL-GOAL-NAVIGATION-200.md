# 局部目标与绕障试验（200）

更新：203已完成接续目标的9段自动实车执行，用户确认避障成功；仍是短走停看，平顺连续行驶尚未实现。最新结果、版本及试验边界见[203记录](LOCAL-GOAL-FIELD-203-2026-11-11.md)，以下保留实现说明和早期调试记录。

用户要求以绕过障碍、到达某地作为目标，不以完成三小步作为任务终点。允许在已确认地板上实际探索，薄纸及约1～2厘米低物不应一律阻挡。当前以起点后摄方向前方40厘米为局部目标，仍需实车完成整个绕行过程。

## 实现

- 沿用本机小型单目模型、实测镜头高度及地板几何，将观察投影到5厘米局部栅格；地板高于参考面不超过2厘米可作为低矮可通过表面，不把纸张颜色本身当作判断依据。
- A*根据车宽、长和设置余量扩展障碍，搜索目标附近的路线。未知空间只用于制定探索方向，下一段平移仍重新观察并经过近处地面及车身余量检查；不要求先拼出完整房间自由空间图。
- 同一原生任务令牌最多80个短动作、10分钟，记录上限相应延长，文件仍限制100MB。旧单步/三步诊断保留原预算。暂停、断连、停止和失效不会自动重新发放任务令牌。
- 转向100/150毫秒、平移150/250毫秒，每次提示后限时停止。航向来自相机/IMU朝向，平移来自连续地板视觉；补偿镜头到履带中心的水平偏移。ARCore原始平移不用于累计到达距离。
- 转向后重看地面，从几个靠下的候选区域选取经过留出点校验的地板假设，同步到地板光流；不是通用语义地面分割。两次新的可见地板观测可清除模型残影，隐藏单元不会凭时间变成空地。
- 手机路线菜单增加“绕障到前方40厘米（局部试验）”。地图右侧显示任务与剩余距离；“停止导航”保持可用。全过程摘要保存本机 `local-goal-mission.json`，家庭图像不进入公开仓库。
