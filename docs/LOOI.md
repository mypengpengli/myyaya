# LOOI 接入调查

调查日期：2026-10-26（Asia/Shanghai）。

## 当前决定与证据范围

用户在本项目会话中确认已购买 LOOI。项目沿用此前确定的自有红米 K50，计划开发可自定义模型与工具的 Android 应用，通过 BLE 接入底座。

本次从[分享链接](https://chatgpt.com/share/6add821d-da34-83ea-96aa-66e60eb30247)读取的正文仍为早期 K50 / ESP32 讨论，没有读到 LOOI 采购后的更新。本文记录已核实的公开资料，不将未读取到的方案细节当成确定要求。

## 待验证事项

1. K50 的 Android 版本、BLE 权限、连接稳定性以及官方 App 实际运行情况。
2. LOOI 具体型号和固件版本，与所选社区实现的适配程度。
3. 手机的磁吸固定方式、安装位置及手机与底座各自的供电方式；不能仅凭磁吸固定判断手机可无线充电。
4. 自定义应用连接后能否读取设备状态；与官方 App 的连接占用如何协调。
5. 停止命令和断连处理是否有效，再测试低速、短时动作；底座传感状态与运动限制需要单独验证。
6. 相机、录音、视频播放与机器人控制并行运行时的资源占用和界面状态。

## 第一轮验收

第一轮目标为：识别 K50 → 识别 LOOI → 连接并读取状态 → 验证停止 → 手动执行受控动作。选择有足够余量的测试区域，避开桌沿；每次动作的完成或失败都要能在界面看到。

NewAPI 问答、手机录像和播放、Hermes 任务接入分别安排后续验收，不用运动控制成功替代它们的功能验证。
