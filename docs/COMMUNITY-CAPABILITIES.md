## 中文语音的实际选择

采用 [Vosk 官方模型目录](https://alphacephei.com/vosk/models) 的 `vosk-model-small-cn-0.22`，约 42 MB 下载、Apache-2.0；官方提供 [Android 离线识别示例](https://alphacephei.com/vosk/android)。归档从官方 HTTPS 地址下载，本次取得的 SHA256 固定为 `3af8b0e7e0f835ae9d414ce5df580237a3cfb08d586c9fbbb0f7ff29ad5b14ba`；这是我们锁定归档的校验值，不冒充发布者另行签发的校验文件。

模型随 APK 提供，安装后不再下载；初次开启会在手机内部展开模型。无需 OpenAI、NewAPI、Azure、Google 语音服务或系统识别器即可执行本地识别。只在用户点击开启且应用位于前台、当前页面可用时采音；退出页面、后台、休眠或点击关闭会停止采音并取消本机动作。权限拒绝、模型错误和采音错误会显示提示，不静默切换云端。

“小丫小丫”是启用监听后的中文识别唤醒，不是低功耗专用唤醒引擎。识别文字中的同音“小鸭小鸭 / 小雅小雅”可作为称呼恢复；不能据此承诺电视噪声、远场或同音人的误唤醒率。动作只接受确定的完整短语，否定句、解释动作、混合长指令不会提取出运动动作。唤醒后 15 秒可连续下达短口令；STOP 接受 partial，无需唤醒、联网或模型规划。

“听写一句话”与动作监听隔离：听写不会因识别出“前进”执行运动，只有 STOP 仍可中断。识别后显示原文，任务页点击“采用这句话”可继续编辑再发送 Hermes。结果增加“朗读结果”。这是一轮可联调的语音入口，尚未实现持续自由对话、边说边打断或 Pi 手机工具循环。

朗读通过 [Android TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech) 选择已安装的中文离线音色；没有中文离线音色就提示安装，不静默调用收费云服务。朗读时关闭识别与本机动作，避免把小丫自己的声音识别为指令；朗读后手动重新开启监听。当前声音不冒充 Azure 晓悠，Azure 资源配置后再替换声音适配。

## 交付与验收

版本 2.1.152 / versionCode 152，包名和永久签名沿用第一版。新包仍为 ARM64，允许对第一版覆盖安装；是否真正保留手机设置与任务数据，需要用户完成覆盖安装验收。

本地包：`mobile/output/android/myyaya-2.1.152-arm64.apk`，约 164.2 MiB，附 `.apk.sha256` 和 `.apk.build.json`。APK SHA256：`5198523a5f0086442830b9a952814b7102c9de7dc67bbb41e829cb301059c0ef`。签名、ZIP 对齐、模型逐文件校验和包内凭据检查已通过，安装包不内置任何用户服务 Token。

同日后续已通过 [GitHub Release v2.1.152](https://github.com/mypengpengli/myyaya/releases/tag/v2.1.152) 公开分发，可直接下载 APK；后续升级入口见[更新说明](UPDATES.md)。

1. 安装后先在未连接底座时开启中文口令，确认权限、加载提示、识别文字和明确的未连接反馈。
2. 开启监听后说“小丫小丫，前进”，再说“后退、左转、右转、抬头、低头、点头、开灯、关灯”；在适合实测的场地逐项确认实际动作和自动停止。
3. 底座控制页先扫描连接，测试触屏动作与始终可点击的红色停止按钮；动作等待传感器时点停止，不应晚启动。
4. 在动作期间说“停止”，并分别测试退出页面、切后台、关闭语音；不能把蓝牙断开后的手机 STOP 当成底座一定已经收到。
5. 在“执行任务”页听写、采用文字、发送 Hermes、查看进度和朗读结果；缺少 Token 时只提示配置，不妨碍本地控制。
6. 允许相机后开启人脸注视，返回表情页点击互动，检查视觉注视与受限头身朝向。该能力不承诺向用户走近、识别身份、房间地图或自主导航。

实际构建/哈希/测试记录见 [VALIDATION](VALIDATION.md)。后续仍需完成 NewAPI 连续对话、Azure 晓悠、媒体工具桥与跟随导航；这些不再作为已有 BLE 和基本语音接线的前置条件。
