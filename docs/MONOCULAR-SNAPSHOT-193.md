# 193：手机完整模型输出与相机单次对照

基于[192手机实测](MONOCULAR-DEPTH-COMPARISON.md)。本修订不新增推理框架，继续复用Sherpa通用ONNX。相对深度尚未用于导航。

## 修改

- 固定输入benchmark结束后，通过原生API只导出四份固定名称、固定尺寸的缓存深度文件，供电脑核对全图。没有任意路径读写接口。
- 新增ADB只读`probe monocular_live`：在已经打开并开始扫描的教路线相机中，取下一帧CPU图像，关闭Image后在后台转换，生成标准行序RGB输入。
- 处理YUV三平面的行间距、像素间距、截断及图像/位姿时间差；关闭或超时会拒绝请求，不把过期结果放到新取样上。
- 本机推理后并排显示拍摄原图和相对深度，明确不是米数。原始取样、元数据和模型输出可通过固定文件导出。这个单次对照没有连续相机推理循环，也不调用电机。
- 保留模型文件独立于APK；当前模型和输入由ADB校验后放入。正式模型下载/导入尚未开发。

## 验证进度

178项原生测试通过，新增YUV填充/像素间距与截断测试；TypeScript、固定输入测试、相机关闭/旧结果拒绝/输出尺寸/会话释放测试通过。正在覆盖安装和手机画面对照验收，尚未把这部分记为手机验收完成。

用户确认罐子直径6.5厘米、高11.5厘米；191之后脖子正常，350毫秒左转当时没留意。不会为肉眼确认再重复该动作。本轮相机/输出对照不需要蓝牙连接；因安装断连可能抬头，后续任何使用10厘米高度的实时米制实验前仍须重新确认最低姿态。
