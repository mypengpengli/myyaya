# 190：未就绪双深度诊断与地图高度失效说明

基于[11月10日四次实体动作](PHONE-CHECK-2026-11-10-FIELD.md)。版本 2.1.190，当前正在进行手机只读回放验收；自主导航尚未完成。

## 修改

- `RoomMapPanel` 不再在诊断入口丢弃未初始化的原始样本。两路的缺失、时间戳、数据新鲜度、非零/0.2～4米像素数量和距离中位数均进入报告；固定参考面可用时也会执行融合对照，明确报告拒绝原因。
- 地形融合仍要求原初始化条件。诊断报告不提供运动授权，缺失或不可信的平滑深度不变成空地。现有局部原始观测和导航脉冲限制保持。
- 本地深度记录升级为 schemaVersion 2，允许某路缺失、参考面尚未建立、原始时间戳过期或为零。按帧时间限速，避免“等原始深度有效才开始采集”的循环条件。
- 开始相机/IMU录像时同步新建 360 帧上限的深度记录，覆盖90秒录像；地板取样区菜单也可单独重新录制，用于无电机回放。原自动诊断仍默认120帧，保留文件数有界。
- `NavigationPoseLock` 和标定结果区分地图高度变化、相机倾角变化和连接变化。地图高度变化仍中止测量，但不再把它说成机械抬头，也不把未完成的位移作为车速标定。
- `summarize_depth_capture.py` 分别统计缺失、全零、过期和近处有效数据；`audit_replay.py` 兼容旧 v1 和新 v2，跳过缺少原始数据或参考面的记录，不补造参考面。

## 验证

175 项原生测试通过（头部7、导航168），含实际第二次动作的地图高度/倾角数值回归。新增 Python 记录摘要4项测试、TypeScript 检查和导航控制/取消回归通过。此轮尚没有190实体运动结果；将先用189刚采的录像复核缺失/稀疏深度是否进入诊断文件。

120毫秒左转约1.7°的问题未在本修订中扩大动作时长；后续明显转向测试需要独立安排，不能声称这一版已经完成了角度闭环。
