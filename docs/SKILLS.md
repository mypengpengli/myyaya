# 小丫的技能库

从 2.1.167 起，可以让小丫把成功做法整理成技能，重开 App 后按任务自动使用。技能组合已有手机工具或 Hermes 工作步骤，不修改模型权重，也不会凭一份说明新增原生权限或硬件协议。

## 和 Pi 的关系

小丫使用固定版本 `@earendil-works/pi-agent-core`。Pi 的 [coding-agent Skills](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md) 会先提供名称和简介，再按需读取完整 `SKILL.md`；核心 Agent 提供工具调用和上下文机制，手机存储与技能发现需要应用接入。

本版沿用这种分层，不引入 coding-agent 的 Node 文件系统或终端。手机私有 SQLite 保存技能及版本，按 Agent Skills 的 `name` / `description` frontmatter 生成完整 SKILL.md 内容。目录和本轮加载的说明进入真实 Pi 上下文，执行仍由 Pi 调用实际工具。

## 怎么教小丫

1. 先让小丫实际完成流程，例如“先找最近的照片，再打开并固定”。
2. 说“把刚才成功的做法总结成技能，叫照片回顾，以后我说照片回顾就这样做”。
3. 下次直接说“照片回顾”。匹配具体触发短语时自动加载完整步骤；语义相近时模型也可以通过简介自行读取技能。

也可以直接教一个新流程并保存，尚未实测时来源标为“用户教给”；有真实成功调用依据时标为“经验整理”。经验依据只保存成功工具名称，不保存工具原始结果或密钥。后台任务刚提交不视为已成功，查询到完成后才能作为相应异步工具的成功依据；经验标签不代表所有场景均经过验证。

步骤应描述怎样找当前文件或任务，不写死这一次的作品编号。普通个人偏好继续使用长期记忆，不为每句话生成技能。

## 查看与维护

左滑菜单 → **小丫的技能**：查看步骤、启用/停用、加载次数、来源、历史版本，并恢复旧步骤或分享 SKILL.md 内容。恢复会产生新版本，保留历史。语音也可要求查看、修改、停用、恢复或删除。

Agent 工具：`skill_list`、`skill_read`、`skill_save`、`skill_manage`。更新需先取得当前版本；旧版本写入会拒绝，同内容重试不会重复创建版本。停用或缺少依赖工具的技能不进入自动目录。完整步骤按需读取，每轮最多自动加载两个最具体匹配项，单项最多 6000 字，库容量 40 项，保留最近八个历史版本。

本轮已加载的版本优先，旧对话中的技能内容可能已过期。技能只服务于用户当前任务，不能把“如何做”当作用户已经要求执行。目录加载失败时普通聊天和其他工具仍可继续。

## MCP 扩展边界

Pi 有 [MCP 工具接入](https://github.com/earendil-works/pi/tree/main/packages/agent#mcp-and-codemode)；Skill 描述工作方法，MCP 提供实际调用能力，两者可以组合。未来接入邮箱 MCP 并完成账号授权后，可以保存“查邮件 → 整理摘要 → 制作文档”的技能。

本版没有通用 MCP 连接设置或客户端，不把现有 Hermes 派单接口说成 MCP。远程 HTTPS MCP 可以后续接入手机工具注册层；需要本地进程/stdio 的 MCP 优先运行在服务器。技能依赖按当前实际工具列表检查，缺失工具不能通过保存技能凭空生成。

当前未包含任意脚本执行、第三方 Skill 包及附件安装、从服务器自动同步技能或将技能纳入原有记忆备份。SKILL.md 分享为手动分享内容，不能等同于已接通桌面技能目录的完整导入安装。

验证包括真实 Pi 工具循环、真实 SQLite 持久化、空会话重开后自动使用、语义按需读取、当前作品编号查找、停用/恢复、版本冲突、写入失败与异步提交不冒充完成。手机真实模型结果见[续测记录](PHONE-CHECK-2026-10-29.md)。
