## 已确定的路线

- 用户改用已有的小米 12 Pro，并表示手机已升级澎湃 OS 3；K50 是更早的候选。

## “看向我”与“过来”分开验收

“看向我”的候选闭环为：昵称唤醒 → 相机发现目标 → 计算目标偏离画面中心的方向 → 底盘转向 / 手机俯仰 → 再观察并停止。左右转向与上下俯仰需要分别实测。

“过来”是独立的后续目标，还需要确认目标位置或距离、可走路径、运动反馈及停止条件。至少要在目标丢失、障碍阻挡或连接异常时停止。人脸框大小或人脸身份本身不能替代可通行路径和可靠距离信息。

人物档案计划关联登记身份、人脸特征、声纹及偏好。声纹关联不能单独保证画面中的某张脸就是当前说话人；多人场景要另行验证目标选择。手机内置麦克风能否提供声源方向信息目前未验证。

## USB-C 扩展：研究方向

最新讨论提出保留 LOOI，通过手机 USB-C OTG 扩展缺少的传感器。这条路线先做单设备验证，再考虑组合使用。

| 候选 | 预期用途 | 接入前要核实 |
| --- | --- | --- |
| 2D 激光雷达，如 RPLIDAR C1 | 平面测距，以及后续定位、建图与避障研究 | Android USB / 串口适配、数据解析、安装、供电和稳定采样 |
| 深度相机，如 Orbbec Gemini 2 | 距离与深度信息，用于目标和环境感知研究 | 具体 SDK 支持版本、USB 工作模式、带宽、供电与手机兼容性 |
| 有源 USB Hub | 多外设连接和外部供电 | 数据链路、供电隔离及手机 OTG 的实际兼容性 |

Android 的 USB Host API 提供枚举和通信入口；它不代表任意雷达或相机都可以直接使用。驱动/协议、手机系统权限、安装负载以及多设备带宽和供电需要逐项确认。手机 OTG、无线补电与传感器同时运行也需要实测，暂不写入已支持能力。

雷达、深度相机和 Hub 目前没有得到已采购确认；本项目也尚未实现 SLAM 或自主导航。

## 第二代与软件复用

WAVE ROVER 是用户感兴趣的第二代候选，尚未确认购买。Android 直连导航外设是优先研究方向之一；Raspberry Pi、Orange Pi 或其他 Linux 主机仅作为需要成熟导航栈时的候选协处理器。

上层对话、人物档案、手机工具和 Viewer 尽量独立于底座。身体适配层计划表达连接、停止、移动、头部俯仰、状态和支持能力；先做 LOOI 适配。换成 WAVE ROVER 或其他身体时，需要实现和验证新适配层，不承诺直接更换底座就能运行。

第一代没有新增购买 Linux 主机、雷达或深度相机的要求。导航路线和机械扩展待现有 LOOI 软件与身体能力验证后再选。
