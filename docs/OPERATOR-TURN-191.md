# 191：可选择的较大转向观察动作

用户反馈120毫秒左转不明显；189实跑ARCore估计约1.68°。191在人工标定菜单增加左右转时长选择：120毫秒小动作、350毫秒加大幅度。两种都必须人工确认场地，保留三秒倒计时、取消和自动停止；不把时长当作已经校准的角度。

较长动作使用独立的 `calibration_left/right` 指令，仅接受350毫秒、当前导航占用者、已连接且在前台的通道。复用现有BLE、停止、传感器检查及取消逻辑。普通导航脉冲仍只接受90～250毫秒，AI没有新增任意时长接口。

标定仍在定位失效、地图高度变化、倾斜变化和断连时终止，仍要求停稳后检查转角与转动中心。新增回归检查350毫秒不会从普通导航入口发出、错误时长不能派发、过期控制占用者不能发动作，以及较长测量仍须等待停稳。

当前正在构建和手机界面验收；350毫秒实际角度尚未测得。190的双深度诊断及错误原因分类包含在本版。覆盖安装后蓝牙可能释放、脖子可能自行抬起；下一轮实体测试前由用户手动连接并压回最低，不自动回中。
